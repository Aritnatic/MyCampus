# 🎓 MyCampus

**A verified campus and cross-university collaboration platform.**

MyCampus connects students across universities through AI-powered discovery, verified identities, and real collaboration tools — turning isolated campus communities into one connected network.

---

## ✨ Features

- 🔍 **AI-Powered Semantic Search** — find people, projects, and resources by meaning, not just keywords
- ✅ **Verified Identity Layer** — every user is a verified student, keeping the platform trustworthy
- 🤝 **Cross-University Collaboration** — connect and work with students from other campuses, not just your own
- 🌐 **Live Deployment** — hosted on GitHub Pages, built with React + Vite

---

## 🛠️ Tech Stack

| Layer      | Tech            |
|------------|-----------------|
| Frontend   | React, Vite     |
| Deployment | GitHub Pages, GitHub Actions |

## 🚀 Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/GUD-marani-org/mycampus.git
cd mycampus
npm install
npm run dev
```

The app will be running locally — check your terminal for the local dev URL.

### Build for production

```bash
npm run build
```

### Deploy to GitHub Pages

```bash
npm run deploy
```
